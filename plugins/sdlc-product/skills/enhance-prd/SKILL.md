---
name: enhance-prd
description: Turn a tracker ticket into a PRD. Use when a ticket is in the PRD stage.
---
Write a PRD for the ticket with these sections: Problem, Users, Goals, Non-goals, User stories, Acceptance criteria (numbered, testable), Open questions, Risks.
Read the ticket, its comments, and the app (README, AGENTS.md, the UI code) so the PRD fits what exists.
Do not write code, create branches, push, or open PRs. Keep it under 600 words.
